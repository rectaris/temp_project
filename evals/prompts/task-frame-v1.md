# Evaluation task frame

You are working in a Git repository that holds a small software project.
Complete the task described after this frame by editing the repository files.

- Change only the files the task needs.
- Do not edit the tests unless the task asks for it.
- Do not create commits, branches or tags; leave your changes in the working tree.
- Do not use the network for anything other than your own model access.
- When you finish, stop. Your work is judged only by running the project's checks on your changes.
